# supernotes-releases-heimnetz

Update-Kanal der Desktop-App **„SuperNotes Heimnetz"** (Profil `heimnetz`).

Dieses Repository enthält nur veröffentlichte, signierte und notarisierte Pakete (GitHub-Releases),
keinen Quellcode. Installierte Apps lesen von hier `latest-mac.yml` und spielen neue Fassungen
nach Zustimmung ein. Die App spricht ausschließlich mit einem Heimnetz-Server unter
`https://supernotes.local`.
